# Swiggy-s-Restaurant-Recommendation-System
This project is a restaurant recommendation system that suggests restaurants based on user preferences such as city, rating, cost, and cuisine. It uses clustering techniques to group similar restaurants and return personalized results.

📌 Features
✅ Accepts user input for city, rating, cost, and cuisine
✅ Clusters restaurants using KMeans
✅ Built with Streamlit for an interactive UI
